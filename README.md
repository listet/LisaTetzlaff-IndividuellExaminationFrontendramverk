# LisaTetzlaff-IndividuellExaminationFrontendramverk

För att köra appen: kör "npm i" samt därefter "npm run dev" i terminalen

## Where It's @

Jag har använt mig av två ytterligare Hooks:
**useNavigate** samt **useLocation**.

### useNavigate
useNavigate har jag använt mig av för att på ett enkelt och smidigt sätt transportera mig från eventPage in i Eventet. Vi använde denna hook i gruppuppgiften och upplevde att den fungerade smidigt och enkelt i navigations-syfte. 

### useLocation
När jag letade runt bland olika hook´s att använda kändes useLocation som en användarvänlig och lättanvänd hook. Jag valde att använda den för att uppdatera min Nav i samband med att path förändrades då den känner av path-förändringar.
